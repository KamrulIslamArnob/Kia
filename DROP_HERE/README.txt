DROP FILES HERE FOR ZERO-TOUCH AI VIDEO EDITING
===================================================

You don't need to open project folders manually if you don't want to!

Option A (Recommended — Easiest):
  Open the Studio Hub UI in your browser: http://localhost:4400
  (or double-click Start-Video-Studio.bat in the main folder).
  Upload raw videos, paste YouTube/TikTok/Reels/Drive/MP4 links,
  upload reference videos/images, logos, audio, and type instructions.

Option B (Quick Folder Drop):
  Drop files into any of these folders while Studio Hub is running:
  - DROP_HERE/raw-video/   -> Raw screen recordings or camera footage
  - DROP_HERE/references/  -> Reference videos, inspiration clips, moodboards
  - DROP_HERE/images/      -> Logos, product photos, screenshots
  - DROP_HERE/audio/       -> Voiceovers, background music, sound effects

Studio Hub automatically moves dropped files into the active project's
inbox/ and assets/ folders, analyzes resolution/duration/FPS with FFprobe,
generates thumbnails, and updates AI_READY_PROMPT.md so the AI agent
can immediately edit and render your video.
